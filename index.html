راهنمای جامع تگ‌های HTML

مرجع سریع گروه‌بندی شده بر اساس نقشه راه

Introduction & Basics

شروع کار
بسته block

<!DOCTYPE>

نوع سند را تعریف می‌کند.

بسته block

<html>

ریشه یک سند HTML را تعریف می‌کند.

بسته none

<head>

شامل متادیتا/اطلاعات برای سند است.

بسته block

<body>

بدنه سند را تعریف می‌کند.

Textual Tags

متن و تیترها
بسته block

<h1> to <h6>

سرتیترهای HTML را تعریف می‌کند.

بسته block

<p>

یک پاراگراف را تعریف می‌کند.

باز inline

<br>

یک خط شکسته ساده را تعریف می‌کند.

باز block

<hr>

یک تغییر موضوعی در محتوا را تعریف می‌کند (خط افقی).

بسته block

<pre>

متن از پیش فرمت شده را تعریف می‌کند.

بسته block

<blockquote>

بخشی که از منبع دیگری نقل شده است را تعریف می‌کند.

Links & Embedding Media

لینک و رسانه
بسته inline

<a>

یک هایپرلینک را تعریف می‌کند.

باز inline

<img>

یک تصویر را تعریف می‌کند.

بسته inline

<audio>

محتوای صوتی جاسازی شده را تعریف می‌کند.

بسته inline

<video>

محتوای ویدیویی جاسازی شده را تعریف می‌کند.

بسته inline

<iframe>

یک فریم درون خطی را تعریف می‌کند.

Lists and Types

لیست‌ها
بسته block

<ul>

یک لیست نامرتب را تعریف می‌کند.

بسته block

<ol>

یک لیست مرتب را تعریف می‌کند.

بسته list-item

<li>

یک آیتم لیست را تعریف می‌کند.

بسته block

<dl>

یک لیست توصیفی را تعریف می‌کند.

بسته block

<dt>

یک اصطلاح/نام را در لیست توصیفی تعریف می‌کند.

بسته block

<dd>

توضیح/مقدار یک اصطلاح را در لیست توصیفی تعریف می‌کند.

Table Tag

جداول
بسته table

<table>

یک جدول را تعریف می‌کند.

بسته table-row

<tr>

یک ردیف در جدول را تعریف می‌کند.

بسته table-cell

<td>

یک سلول در جدول را تعریف می‌کند.

بسته table-cell

<th>

یک سلول هدر در جدول را تعریف می‌کند.

بسته table-header-group

<thead>

محتوای هدر را در جدول گروه‌بندی می‌کند.

بسته table-row-group

<tbody>

محتوای بدنه را در جدول گروه‌بندی می‌کند.

Using Forms

فرم‌ها
بسته block

<form>

یک فرم HTML برای ورودی کاربر تعریف می‌کند.

باز inline-block

<input>

یک کنترل ورودی را تعریف می‌کند.

بسته inline

<label>

یک برچسب برای عنصر <input> تعریف می‌کند.

بسته inline-block

<textarea>

یک کنترل ورودی چند خطی را تعریف می‌کند.

بسته inline-block

<button>

یک دکمه قابل کلیک را تعریف می‌کند.

بسته inline-block

<select>

یک لیست کشویی را تعریف می‌کند.

Semantic Markup

معنایی
بسته block

<header>

یک هدر برای یک سند یا بخش تعریف می‌کند.

بسته block

<nav>

لینک‌های ناوبری را تعریف می‌کند.

بسته block

<main>

محتوای اصلی یک سند را مشخص می‌کند.

بسته block

<article>

یک مقاله را تعریف می‌کند.

بسته block

<section>

یک بخش در یک سند را تعریف می‌کند.

بسته block

<aside>

محتوایی جدا از محتوای صفحه تعریف می‌کند.

بسته block

<footer>

یک فوتر برای یک سند یا بخش تعریف می‌کند.

Styling & JavaScript

استایل و اسکریپت
بسته none

<style>

اطلاعات استایل را برای یک سند تعریف می‌کند.

باز none

<link>

رابطه بین سند و منبع خارجی را تعریف می‌کند.

بسته none

<script>

یک اسکریپت سمت کلاینت را تعریف می‌کند.

بسته block

<div>

یک بخش در یک سند را تعریف می‌کند (کانتینر عمومی).

بسته inline

<span>

یک بخش درون خطی در یک سند را تعریف می‌کند.
