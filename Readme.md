## 🪐 این پروژه چیه؟

**HTML Tag Galaxy** یه پروژه‌ی متن‌باز (Open Source) و **بلندمدته** که هدفش اینه تمام تگ‌های HTML رو به صورت **گروه‌بندی‌شده**، **دسته‌بندی‌شده** و با **ظاهری شبیه کارت‌های iOS** توی یه صفحه‌ی واحد نمایش بده.

تصور کن یه مرجع HTML که هم **خوشگله**، هم **کاربردیه**، هم **سریع** و هم **بدون پیچیدگی**! 😍

---

## ✨ چه ویژگی‌هایی داره؟

- 🎴 **کارت‌های iOS-Style**: با گوشه‌های گرد، افکت شیشه‌ای (Glassmorphism) و سایه‌های نرم.
- 🌌 **تم کهکشانی (Galaxy Theme)**: پس‌زمینه‌ی تیره با گرادیان‌های بنفش، آبی و صورتی.
- 📦 **گروه‌بندی منطقی**: تگ‌ها بر اساس نقشه‌راه‌های معتبر (Roadmap.sh) دسته‌بندی شدن.
- 🏷️ **لیبل‌های هوشمند روی هر کارت**:
  - **نوع تگ**: باز (`<img>`) یا بسته (`<div>`)
  - **نوع Display**: `block`, `inline`, `inline-block`, `none`, `table-row` و...
- 📜 **تک‌صفحه‌ای (SPA)**: همه چیز توی یه صفحه، بدون رفرش!
- 📱 **ریسپانسیو**: روی موبایل، تبلت و دسکتاپ عالی دیده می‌شه.
- 🎨 **افکت‌های تعاملی**: با هاور کردن روی کارت‌ها، افکت سه‌بعدی (Tilt) فعال می‌شه.
- 🧠 **محتوای دقیق**: توضیحات تگ‌ها از منابع معتبر استخراج شده.

## 🪐 What Is This Project?

**HTML Tag Galaxy** is an **open-source**, **long-term** project that aims to display all HTML tags in a **grouped**, **categorized**, and **iOS-inspired card layout** — all on a single page.

Imagine an HTML reference that is **beautiful**, **practical**, **fast**, and **simple**! 😍

---

## ✨ Features

- 🎴 **iOS-Style Cards**: Rounded corners, glassmorphism effect, and soft shadows.
- 🌌 **Galaxy Theme**: Dark background with purple, blue, and pink gradients.
- 📦 **Logical Grouping**: Tags are categorized based on trusted roadmaps (Roadmap.sh).
- 🏷️ **Smart Labels on Each Card**:
  - **Tag Type**: Open (`<img>`) or Closed (`<div>`)
  - **Display Type**: `block`, `inline`, `inline-block`, `none`, `table-row`, etc.
- 📜 **Single Page (SPA)**: Everything on one page, no refresh needed!
- 📱 **Responsive**: Looks great on mobile, tablet, and desktop.
- 🎨 **Interactive Effects**: Hovering over cards triggers a 3D Tilt effect.
- 🧠 **Accurate Content**: Tag descriptions are extracted from reliable sources.

---

## 🚀 How to Run It?

Super simple! You only need 3 files:

1. `index.html`
2. `style.css`
3. `script.js`

Just open `index.html` in your browser and enjoy! 🌠

> No packages or extra tools needed. Pure HTML/CSS/JS!
